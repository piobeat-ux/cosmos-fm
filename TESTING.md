# Проверка Cosmos FM

## Автоматические проверки

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm audit --audit-level moderate
```

Тесты не используют production/секреты. PGlite загружает исходную тестовую схему и реальные миграции: сохранность данных, права пользователей, отсутствие автоповышения прав, расписание/пересечения, публикация и атомарность сохранения.

Тесты плеера используют управляемый аудиообъект для проверки Play/Pause, поздних ответов, смены источника, завершения записи, последовательных эфиров и ошибок.

## Изолированный интерфейс

```sh
pnpm exec vite --config tests/ui/vite.config.ts
```

Откройте http://127.0.0.1:5174/tests/ui/index.html. Стенд использует настоящие компоненты календаря/редактора и временную PGlite-базу с миграциями и двумя тестовыми записями. Изменения исчезают при перезапуске. Стенд не входит в production-сборку, не использует рабочий Supabase и не имитирует Auth/Storage/TUS.

1. Передача в среду 10:00, публикация, еженедельный повтор.
2. Пересечение 10:05 отклоняется; соседний эфир 10:10 сохраняется.
3. В следующей неделе остаётся только повторяющаяся запись.
4. Дополнительный эфир существующей записи не скрывает её из каталога.
5. Проверить черновик, отмену, удаление, месяц/неделю/день, ввод времени и перемещение.
6. Ошибки сохраняют введённые данные и не закрывают диалог.

## Preview с реальным Supabase

- Анонимный/обычный пользователь не может менять данные через прямой API; profiles.role не даёт права администратора.
- MP3 загружается частями; >50 МБ, >60 минут, пустые и переименованные не-MP3 отклоняются.
- Проверить отмену, сетевой разрыв, повтор, истечение сессии, внешний CORS. До окончания загрузки карточка не сохраняется.
- Запланированная новая запись скрыта до первого завершённого эфира; draft не выдаёт URL; текущий эфир доступен.
- После открытия нужен Play; середина эфира даёт правильную позицию. Запись доигрывает, следующий эфир включается напрямую, иначе возвращается радио.
- Ручная запись не прерывается сеткой. Stop/новый выбор не отменяются старым ответом.
- Проверить Safari/iOS и Chromium/Android, возврат из фона, восстановление сети и доступность источников в целевых сетях. Эмуляция ширины не проверяет ограничения мобильного звука.

## Production

После выпуска проверить доступность без автозвука, сохранность данных/файлов, вход согласованного администратора, сетку, API-права и заголовки ответа. Не засорять публичный эфир тестами; использовать согласованную короткую запись и удалять только точно идентифицированные тестовые данные.

## Границы доказательств

PGlite не проверяет hosted Auth, PostgREST, Storage или конкуренцию нескольких серверных соединений. Локальный стенд не является production-проверкой. Чистый audit означает отсутствие известных предупреждений на момент проверки, а не гарантию отсутствия уязвимостей.
