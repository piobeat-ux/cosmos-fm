# Cosmos FM

Интернет-радио с каталогом передач/подкастов и календарём эфиров.

## Архитектура

React 18, TypeScript, Vite 8, Tailwind CSS 3, FullCalendar 6. Supabase предоставляет PostgreSQL, Auth и Storage; Vercel размещает статический клиент. Внешний радиопоток настраивается в админ-панели.

Плеер переключает источники на устройстве слушателя по расписанию и серверному времени. Это не серверный микшер или единый Icecast/HLS-поток. Работа в фоне зависит от ограничений браузера.

## Разработка

Требуются Node.js 24 и pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

В локальном окружении задайте:

```dotenv
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

Все переменные VITE попадают в браузер. Никогда не помещайте туда service_role, пароли БД и другие секреты. Доступ защищается серверными правами и RLS.

Миграции рассчитаны на существующую схему проекта, а не на пустую базу. Локальная разработка с production-переменными обращается к рабочей базе: не выполняйте там пробные записи. Для проверки форм используйте [изолированный стенд](TESTING.md).

## Админ-панель

Откройте `/#/admin` и войдите в заранее созданную учётную запись Supabase. Администраторов назначают отдельно через доверенное подключение к БД; регистрация и старое поле profiles.role таких прав не дают.

- MP3 до 50 МБ (50 000 000 байт), не более 60 минут: файл либо проверяемая HTTPS-ссылка.
- Новой записи можно назначить первый эфир при загрузке; тогда она появится в каталоге после его завершения. Без расписания возможна немедленная публикация.
- Календарь: месяц/неделя/день, московское время UTC+03:00, перенос мышью, черновики, публикация, необязательный еженедельный повтор и его дата окончания.
- Перенос повторяющегося эфира меняет всю серию. Отдельных исключений для одного повтора пока нет.
- Длительность берётся из MP3. Пересечения опубликованных эфиров отклоняются БД.
- Для замены аудио или снятия записи с публикации сначала снимите её эфиры с публикации.
- Дополнительный эфир не скрывает уже опубликованную запись из каталога.

## Плеер и загрузка

Звук начинается после Play. Эфир открывается с текущей позиции, доигрывает и передаёт управление следующей программе либо радио. Ручное прослушивание каталога не прерывается расписанием; после него возобновляется станция. Ошибка файла приводит к попытке включить радио.

Загрузка частями переживает кратковременные сетевые сбои, но не обещает продолжения после закрытия вкладки. Час MP3 при 96 кбит/с занимает примерно 43 МБ. Внешний источник должен разрешать чтение из браузера через CORS; его содержимое контролирует владелец внешнего сервера.

```sh
pnpm check

```

См. [проверки](TESTING.md), [выпуск и восстановление](DEPLOYMENT.md), [состояние реализации](docs/implementation-status.md).

Manifest и значок есть, но offline-режим радио не обещается. Старые инструкции с отключением RLS, автосозданием администратора и публичной записью в Storage удалены; не применяйте их из истории Git.
